## 👨‍💻 Sobre mí

<img align="right" width="400" src="https://github-readme-stats.vercel.app/api?username=PabloDev24&show_icons=true&rank_icon=github&locale=es&hide_border=true&bg_color=0D1117&title_color=58A6FF&icon_color=1F6FEB&text_color=C9D1D9" alt="GitHub Stats"/>

Soy **Full-Stack Developer** y construyo productos completos: desde la interfaz y la app móvil hasta la API, la base de datos y el despliegue.

- 🌐 **Web:** React, Next.js, TypeScript, shadcn/ui, Bootstrap y Vite.
- ⚙️ **Backend:** Java + Spring Boot, Node.js, NestJS, Express y .NET (C#).
- 📱 **Mobile:** Android con Kotlin.
- 🤖 **IA:** sistemas **RAG** con **ChromaDB** y Python.
- 🗄️ **Datos:** SQL Server, MySQL Workbench, MongoDB, Supabase, Redis y Data Warehouse en SQL.
- 🐳 **DevOps:** Docker, Git, CI/CD, AWS y Azure.
- 🎮 **Extra:** videojuegos con **Godot Engine** y proyectos de hardware con **Arduino**.
- 🗣️ Español nativo · Inglés **B2**.
